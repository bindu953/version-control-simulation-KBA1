# Version Control Simulation

## About My Project

This is a simple HTML project I created for my Version Control assignment. In this project, I practiced using Git and GitHub to make changes to my code and create different branches and resolve conflicts and merge the code into Main branch.

## Tools I Used

- HTML
- Git
- GitHub
- Visual Studio Code

## What I Did

- Created Local folder version-control-SBA1.
- Initialize a new Git repository
- Created a index.html page with starter html code.
- Add the index.html page and commit the code.
- Added a header using the `feature/header` branch.
- Edit index.html by adding header tag and commit the changes.
- Switch back to the main branch.
- Added a footer using the `feature/footer` branch.
- Edit index.html by adding footer tag and commit the changes.
- Practiced switching between branches.
- Switch back to feature/header and add a new footer underneath current header.
- Switch back to the main branch.
- Merge feauture/footer branch into main branch.
- Merge feauture/header branch into main branch.
- Resolve the merge conflict on VS Code.
- Add and commit index.html after all conflicts are resolved.
- Created a new version-control-SBA1 GitHub repository.
- Pushed my code to the newly created GitHub Repository.

## What I Learned

I learned how to create branches and make changes without affecting the main branch. I also learned how to merge branches and fix conflicts when Git cannot combine changes automatically.

This project helped me understand how Git and GitHub are used to manage code.

## How to View My Website

1. Download the project from GitHub.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser.

## Conclusion

This assignment helped me get hands-on practice with Git commands, branching, merging, and resolving conflicts. I am still learning Git, and this project helped me understand it better.
